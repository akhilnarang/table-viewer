Drop a file here CSV, TSV, Excel (.xlsx, .xls), ODS, or JSON. Or . Or paste a link above. You can also press Ctrl+V to paste a file, CSV text, or a link.
Tips and shortcuts
  • Open a link directly: add ?url=https://… to this page address. You can bookmark it.
  • Click a column name to sort. Click again to reverse. Click a third time to remove the sort.
  • Drag the right edge of a column name to change the width. Double-click the edge to fit the content.
  • Click a cell to select it. Double-click it, or press Enter, to see the full value and copy it.
  • Use the arrow keys to move between cells. PageDown and PageUp change the page.
  • Ctrl+F moves the cursor to the search box. Esc clears the search.
  • Set "Header row" to 0 if the file has no column names.
